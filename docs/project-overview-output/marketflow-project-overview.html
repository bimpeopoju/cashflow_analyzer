Project Overview

MarketFlow turns daily trader activity into cash-flow clarity.

A Django + React prototype for Nigerian market traders, covering authentication, daily sales, expenses, inventory, dashboard analytics, reports, and a documented reconstruction path for deeper accounting correctness.

Implemented Screens

Sales, expenses, inventory, reports, and profile are built as separate routed pages.

Sales

Add item name, amount, quantity, and note. View and delete recent sale records.

/sales

Expenses

Track cost category, amount, and notes. Expenses feed dashboard and reports.

/expenses

Inventory

Track item, quantity, unit, reorder level, unit cost, stock value, and low-stock state.

/inventory

Reports

Simple profit, current capital, tax set-aside, and weekly sales/expense movement.

/reports

Auth

Email/password register and login, token storage, refresh, logout, and `/auth/me` profile.

/auth

Profile

Account, business, stall, initial capital, and sign-out action.

/profile

Architecture Direction

The reconstruction blueprint moves from prototype boundaries to domain boundaries.

UsersIdentity, auth, preferences
BusinessesOwnership, stalls, memberships
TransactionsSales, expenses, inventory

Ledger

Normalize cash and capital movement so cash flow is not confused with profit.

Analytics

Centralize revenue, COGS, gross profit, net profit, dashboards, and trend services.

Planning

Add burn rate, runway, break-even scenarios, tax estimates, and forecasting.
